# 誕生日プレゼントサイト

スマートフォン閲覧向けの誕生日サイトです。
5個のプレゼントをタップすると、それぞれの内容がポップアップで表示されます。

## 画像の差し替え方

`assets` フォルダに次の2枚を入れてください。

- `present.png`
  - 5個のプレゼントボックスに使われる画像です。
  - 透過PNGがおすすめです。
  - 正方形に近い画像だときれいに表示されます。

- `illustration.png`
  - 3番のプレゼントを開いたときに表示される画像です。
  - 透過PNGまたは通常のPNG/JPGが使えます。
  - ファイル名を変える場合は、`index.html` または `script.js` 内の画像名も変更してください。

現在は確認用の仮画像が入っています。
自分で描いた画像を同じファイル名で上書きすれば差し替え完了です。

## 開き方

`index.html` をダブルクリックするとブラウザで確認できます。

## 内容を変更する場所

`script.js` の `giftData` 内を書き換えると、各プレゼントの文言を変更できます。

## 公開する場合

GitHub Pagesなどに、フォルダ内のファイルをすべてアップロードしてください。
