【HBD-NAO 更新版】

■ 追加した機能
・最初に「Naooogle」の計算問題画面を表示
・問題は2桁＋2桁で、ページを開くたびに変化
・正解するとHappy Birthdayページへ切り替え
・プレゼントを5個から6個へ変更

■ プレゼント内容
1：はずれ
2：メッセージのプレゼント
3：はずれ
4：イラストのプレゼント
5：ヒント（あたりは3つ）
6：イラストのプレゼント

■ 自分の画像に差し替える場所
assets/present.png
  → 6個すべてのプレゼントボックス画像

assets/illustration4.png
  → 4番を開いたときのイラスト

assets/illustration6.png
  → 6番を開いたときのイラスト

同じファイル名のPNG画像で上書きしてください。

■ GitHub Pagesへの反映方法
HBD-NAOリポジトリにある既存ファイルを、このフォルダ内のファイルで置き換えてCommitしてください。
URLはこれまでと同じです。
